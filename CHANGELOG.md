# Changelog

All notable changes to this project are recorded here. The format follows
Keep a Changelog. Versions follow semantic versioning.

## [0.1.0] — 2026-11-20

### Added

- Initial deterministic, read-only macOS posture audit.
- 24 checks across system, data, network, execution, accounts, management and
  backup.
- Stable JSON schema and human/quiet reports.
- Exit codes for CI use.
- `install.sh`, `run.sh` and `verify.sh`.
- Unit tests with a fake command runner.
- macOS GitHub Actions workflow.
- Check reference, install guide, contributing and security policies.
